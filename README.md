# Посох жителя

Мод для **Minecraft Java 1.21.11 / Forge 61.2.0 или 61.2.1**. Java игры: 21.

## Как установить

1. Установите Forge для Minecraft **1.21.11**: https://files.minecraftforge.net/net/minecraftforge/forge/index_1.21.11.html
2. Выберите в лаунчере профиль Forge. Для тестов используйте отдельную папку игры и новый творческий мир.
3. Скопируйте `villagerstaff-0.4.0.jar` из папки `build/libs` в папку `mods` этой установки.
4. Запустите игру. Посох находится во вкладке боя творческого инвентаря.
5. Либо включите команды и выполните:

```
/give @s villagerstaff:villager_staff
```

Для друзей нужны одинаковые версии игры, Forge и мода. На выделенном сервере этот JAR тоже кладётся в `mods`.

## Способность

- Наведитесь на блок на расстоянии до 48 блоков и нажмите ПКМ.
- Столб светлых частиц высотой 40 блоков обозначает небесный луч; зелёное кольцо отмечает радиус удара.
- Радиус: 10 блоков. Урон: 16 единиц (8 сердец до модификаторов защиты).
- Перезарядка: 45 секунд, общая для всех копий посоха у игрока.
- Промах в небо не расходует перезарядку.
- Владелец и союзники защищены; урон остальным существам, включая жителей, возможен.
- Для игроков соблюдаются правила PvP сервера. В точке удара происходит взрыв с разрушением блоков в пределах 10 блоков от центра. Форма воронки зависит от взрывоустойчивости материалов; обсидиан и бедрок не уничтожаются обычной силой этого взрыва. Огонь не появляется.
- Луч работает и в помещении. В первой версии урон применяется сразу, визуальный эффект сделан стандартными частицами.
- Рецепт пока отсутствует: первый прототип выдаётся в творческом режиме или командой.

## Разработка

`./build-mod.ps1` — сборка. `./build-mod.ps1 -Client` — тестовый клиент. `./build-mod.ps1 -Server` — тестовый сервер.

Локальные Java 8, 21 и 25 находятся в `.tools`; системная Java не меняется. Gradle скачивает зависимости при первой сборке. Java 8 нужна конвертеру имён Forge, Java 25 нужна инструменту Mavenizer, исходный код мода компилируется для Java 21.

`tools/Generate-Model.ps1` создаёт редактируемую объёмную JSON-модель из простых элементов с текстурами Minecraft. Её можно импортировать в Blockbench как Java Block/Item. Генератор перезаписывает модель — не запускайте его после ручного редактирования без сохранения своей копии.

Эскиз: `design/villager-staff-concept.png`. Создан встроенным imagegen по выбранному варианту 3: деревянная рукоять, жёлтая сфера, золотая солнечная оправа, небольшие изумрудные вставки. Игровая модель упрощена под геометрию Minecraft.

## Проверка в игре

- Найти посох в творческом инвентаре и выдать командой.
- Проверить модель в инвентаре, обеих руках и от третьего лица.
- Ударить рядом с несколькими мобами: урон только в радиусе, владелец цел.
- Повторный ПКМ во время перезарядки не создаёт удар; через 45 секунд снова работает.
- Промах в небо не включает перезарядку; проверить дальность 48 блоков.
- Проверить разрушение земли/камня и сохранность блоков за радиусом 10 блоков; учитывать вторичные взрывы TNT.
- На сервере проверить видимость эффекта у друга и PvP при включённом/выключенном режиме.

## Изменения 0.2.0

Радиус 10 блоков, разрушающий взрыв, перезарядка 900 тиков (45 секунд при 20 TPS). Урон существам остаётся 16 единиц; взрыв не добавляет второй урон или отбрасывание. Вторичные эффекты разрушения (падение, лава, активированная TNT) могут причинить вред владельцу и выйти за границу первоначального взрыва. ## Корона короля — версия 0.3.0

В этой версии находятся и взрывной посох, и корона. Замените предыдущий JAR единственным `villagerstaff-0.4.0.jar`.

Команда: `/give @s villagerstaff:kings_crown`. Корона также есть во вкладке боя творческого инвентаря. Рецепта пока нет.

- Надевается в слот шлема, в том числе правой кнопкой мыши.
- Даёт +10 единиц максимального здоровья (+5 сердец), только пока надета. При обычных 10 сердцах максимум становится 15. Новые сердца заполняются обычным лечением; повторное надевание не лечит.
- Защита взята непосредственно у незеритового шлема: 3 брони, 3 твёрдости брони, 0.1 сопротивления отбрасыванию. С версии 0.3.1 корона имеет встроенный компонент UNBREAKABLE: прочность не расходуется, корона не ломается от износа.
- Зачарование «Защита V» встроено: в творческой вкладке присутствует сразу, после команды добавляется при ближайшем тике инвентаря. Снятая точилом «Защита» восстанавливается; другие чары сохраняются.
- Золотая открытая корона с зубцами и красным камнем. Генератор редактируемой модели: `tools/Generate-Crown.ps1`.

Проверка 0.3.0: компиляция и сборка успешны. В мире нужно проверить 15 сердец при надевании, возврат прежнего максимума при снятии, отсутствие бонуса в руке, «Защиту V» после команды и отображение на голове через F5.

Клиент 0.3.0 запущен: загрузка ресурсов завершена без ошибок короны/модели; остаётся штатная ошибка авторизации Realms тестового клиента. Игровая проверка бонуса здоровья и вида на голове ещё не выполнена.


## Изменение 0.3.1

Короне добавлена бесконечная прочность через стандартный компонент Minecraft UNBREAKABLE.


## Меч короля — версия 0.4.0

Команда: `/give @s villagerstaff:kings_sword`. Также доступен во вкладке боя. Этот JAR включает меч, корону и посох; оставьте в mods только одну версию мода.

- Урон полностью заряженного обычного удара: 11 единиц до защиты. Скорость атаки: 1.6. Прочность бесконечна.
- ПКМ: метка «Цель короля» на живую сущность под прицелом в пределах 32 блоков, без наведения сквозь блоки. Длительность **40 секунд**, перезарядка **35 секунд**.
- Метка увеличивает на **20% итоговый урон здоровью** после брони, сопротивления и поглощения, от любого источника, обрабатываемого Minecraft как урон. Не отменяет неуязвимость. Множественные метки не складываются.
- Shift+ПКМ: телепортация рядом с вашей помеченной целью. Отдельная перезарядка **50 секунд**; длительность метки не обновляется. Если метка истекла, нужно наложить новую.
- Для телепортации цель должна быть жива и загружена в том же измерении. Проверяются свободное место, твёрдая опора, отсутствие жидкости, огня и магмового блока. Если место не найдено, перезарядка не расходуется. Верхом на существе телепортация не выполняется.
- Перезарядки привязаны к игроку и общие для всех копий меча; смена руки/меча их не сбрасывает. Остаток времени показывается сообщением при попытке применения.
- Новая метка снимает предыдущую с доступной цели владельца. Если два игрока пометили одну сущность, право телепортации получает последний владелец метки. После выгрузки цели прежняя метка может сохраниться до истечения эффекта, но телепортироваться к выгруженной цели нельзя.
- Меч и корона включены в стандартные теги `minecraft:swords` и `minecraft:head_armor`, поэтому принимают соответствующие зачарования через стол/наковальню. Встроенная «Защита V» короны остаётся.
- Рецепта пока нет. Выбран первый эскиз: широкий чёрный клинок с золотой окантовкой и голубой полосой. Генератор модели: `tools/Generate-Sword.ps1`.
- Лист эскизов: `design/kings-sword-variants.png`, встроенный imagegen. Запрос: четыре варианта широкого королевского меча в стиле Minecraft, чёрный клинок, золотая гарда и окантовка, голубые вставки; выбран вариант 1.

Проверка 0.4.0: сборка успешна, JSON-ресурсы проверены. Игровые сценарии для проверки: удар 11; метка исчезает через 40 секунд; одинаковый источник урона с меткой даёт x1.2; повторный ПКМ блокируется 35 секунд; Shift+ПКМ блокируется 50 секунд независимо от метки; промах/отсутствие места не расходует способность; зачарования меча и короны доступны. Эти игровые проверки пока не выполнены.
